## 4种容易多扣钱的情况

阿里云官方计费文档里专门有一条FAQ，标题就叫“为什么我的云安全中心突然产生了按量付费”。文档列出的原因加上计费规则本身，可以归成四种情况。

**1. 资源包到期或用尽后自动转按量付费。** 官方文档写得很明确：漏洞修复资源包这类抵扣包，额度用尽或到期后，只要对应的按量付费开关没关，系统会自动转成按量付费继续计费，不会自动停止服务。买ECS时顺手领取的云安全中心试用资源包就属于这一类——领的时候免费，用完开始扣钱。

**2. 按量付费的基础服务费是常驻的。** 只要账户下有任何一项按量付费功能处于开启状态，不管有没有资产接入、有没有产生告警，系统都会按小时收取基础服务费（国际站文档标注为0.0072美元/小时，国内站金额以控制台账单为准）。想让这项费用停下来，只能把所有按量付费开关全部关掉。

**3. 退订ECS不会自动停扣。** 云安全中心的按量付费独立于ECS实例计费。服务器退了，这笔费用照走。退服务器之前，先去控制台把相关功能关掉。

**4. 弹性防护默认开启。** 包年包月用户默认开通弹性防护：实际用量超出购买额度时——比如中途又加了几台服务器——超出部分按量计费，按自然日结算。选版本时按“现有服务器加近期要加的量”来算规格，比事后补划算。

真被扣费了也有处理办法：进入云安全中心控制台总览页，在“按量付费服务”区域点“一键关闭”。关闭当天已使用的时长会在次日结算，之后不再产生新账单。想查费用来源，去“我的订单”筛选云安全中心看按量付费的开通时间，或者到操作审计里查具体的开通操作记录。担心欠费的，可以在费用中心设置资金可用额度预警。

## 常见问题

**不买付费版，服务器会受影响吗？**

不会。付费功能没开通，对应的防护只是不生效，不影响服务器本身正常运行，基础版功能继续可用。

**高级版修漏洞还要另外付费吗？**

不用。漏洞修复从高级版开始无需额外付费；免费版不支持这项功能，防病毒版要按2元/次/月单独购买，20次起售。

**包年包月和按量付费能同时开吗？**

可以，但仅限不同功能模块。注意包年包月的版本与按量付费里的“主机及容器安全”只能二选一，不能叠加。

**已经被扣了按量付费的费用，怎么止损？**

控制台总览页一键关闭所有按量付费服务；关闭当天已产生的使用时长次日结算，之后不再出账。
